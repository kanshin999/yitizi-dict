# 字的分身 · 异体字谱

> 输一个汉字，看它历代的异体写法。也可以反过来，用部件把打不出来的字找出来。

在线版：`https://<你的用户名>.github.io/yitizi/`

单个 HTML 文件，12.6 MB，不依赖服务器、不发起网络请求。下载后双击即用，也可以放进任意静态托管。

---

## 能做什么

**查一个字。** 输入简体自动归一到正字，比如输「龟」会走到「龜」的 104 个异体。每个异体标出字号、部首笔画、◎ 或体、↗ 兼正字，点击可以继续往下查它的分身。

**拆一个字。** 打不出生僻字时，把它拆成认识的部件再查。面板里有 147 个高频部件（按笔画递增）和完整 214 部首，点一下加入、再点取消，多选组合即时出结果。缺一个部件的候选会另列一组，标 `2/3` 这样的命中数。

**拆解反查。** 手输框里打一个字，下面直接显示它的构形，如 `麼 = ⿸ 麻 幺`，构件可以点击加入查询。构件不必是部首——「帛」「𡬠」这类面板上没有的也照样能点。

**读释义。** 有《说文》的优先显示《说文》，没有的补《康熙字典》，长文默认收三行，可展开全文。

**看字形。** 宋、楷、行、黑四体切换，大字和异体网格同步变。

## 数据

| 来源 | 内容 | 规模 |
|---|---|---|
| 《異體字字典》〈異體字表〉（2024・正式七版） | 异体与正字的对应，含部首笔画、或体、兼正字 | 74,384 条 |
| 《说文解字》 | 重文，及字头释义与反切 | 1,061 组 / 7,621 字 |
| 《康熙字典》 | 释义（含《广韵》《集韵》反切、韵书出处） | 11,430 字 |
| Unicode Unihan | 异体关系、简繁、部首、笔画、读音 | 3,471 条 |
| CJKVI-IDS | 表意文字构形分解 | 38,425 字 |
| 字典字形图 | 逐字下载后二值化打包 | 40,340 个 |

合计 **20,125 个正字**、**78,016 条异体关系**，其中 **19,051 字（95%）有释义**，**40,340 个字形可直接显示**。

字号规则沿用原典：`A00033-004` 表示常用字表第 00033 号正字的第 4 个异体；`B` 次常用、`C` 罕用、`N` 新增正字。

## 已知限制

**约一半字形无法显示。** 原典中有一部分异体用私用区码位编码，另有部分是图片字形。目前收录了 40,340 个字形位图，占全部异体关系的 52%；剩余部分仍在补充。已下载 50,520 个，未打包的部分受构建环境限制暂未收录。

覆盖率并不均匀：常用字较好（國 97%、為 88%），罕用字偏低（龜 104 个异体只覆盖 5 个，余下多为 C 类罕用字的异体）。

**行书依赖设备字体。** 页面按 `华文行楷 → 手札体 → 楷体` 的顺序回落。Windows 装了 Office 一般有华文行楷，macOS 会退到手札体，手机通常退回楷体。

**没有现代汉语释义。** 释义取自古代字书，是文言原文，未作白话翻译。有 1,074 个字两本字典都未收，会明确标注。

**不能识图。** 曾尝试用字形位图做图像检索，实测对书法、拓片准确率 0–31%（像素比对对非同源字形无效），已移除该功能。识别陌生字形请走「拆解部件」。

## 使用

**本地**：下载 `index.html`，用浏览器打开。iOS「文件」App 的预览不执行 JavaScript，需改用浏览器。

**部署**：把 `index.html` 放进仓库根目录，Settings → Pages → 分支选 `main`、目录 `/ (root)`，一两分钟生效。

---

## 技术

纯静态单文件。数据以 JSON 内嵌，字形图二值化后按位打包、gzip 压缩、base64 内嵌，运行时用 `DecompressionStream` 解压、canvas 逐像素还原。字形可用性在运行时探测，缺字自动降级为位图或占位。

无框架、无构建步骤、无外部 CDN、无追踪代码。
