# 字的分身 · 异体字谱

> 输入一个汉字，看它历代的异体写法。

在线版：`https://kanshin999.github.io/yitizi-dict/`

一个纯静态异体字查询网页。线上版为拆分结构：`index.html` + `data.js` + `glyphs.js` 三个文件需放在同一目录。数据优先从 jsDelivr CDN 加载（加速首屏），失败时自动回退到同目录的本地文件。另附 12 MB 单文件离线版 `yitizi-single.html`，双击即可打开。

---

## 它做什么

汉字的异体不是零散的"错字"，而是同一套构形逻辑在不同时代、不同地域、不同书写场合下的分流。同一句话刻在碑上、抄在纸上、印在书里，往往三个写法。

这个页面把散在字典里的对应关系摊开来看：

- **查一个字** — 输入任意写法，简体自动归一（输「龟」会走到「龜」的 104 个异体）
- **看一条谱系** — 每个异体标注字号、部首笔画、◎ 或体、↗ 兼正字
- **顺着查下去** — 点任一异体，继续查它自己的分身，「来路」可回溯
- **读一段碑文** — 粘贴整段文字，逐字标出异体数量，见字如面
- **两种版式** — 宣纸 / 碑拓
- **字形切换** — 宋 / 楷 / 行 / 黑，主字与异体网格同步
- **拆解部件** — 按部件组合查字，支持缺部件模糊查询
- **导出** — 存成 PNG，方便放进笔记

## 数据

| 来源 | 内容 | 规模 |
|---|---|---|
| 《異體字字典》〈異體字表〉（2024・正式七版） | 异体字与正体字的对应，含部首笔画、或体、兼正字 | 74,384 条 |
| 《说文解字》 | 重文（古文、或体、篆文） | 1,061 组 |
| Unicode Unihan 数据库 | 异体关系、简繁对应、部首、笔画、读音 | 3,471 条 |

合计收录 **20,125 个正字**、**78,016 条异体关系**，其中 **27,983 个字形可在本页直接显示**。

字号规则沿用原典：`A00033-004` 表示常用字表第 00033 号正字的第 4 个异体；`B` 次常用、`C` 罕用、`N` 新增正字。

## 已知限制

**约三分之二的字形无法在本页显示。** 原因是该字典的编码方式：

- 35,672 条异体用的是私用区码位（U+F0000 段），需要专用字库才能渲染
- 14,361 条只有图片字形，图片接口对批量访问不开放

这些条目仍在数据中，以折叠区列出字号与部首笔画，可据此到[《異體字字典》](https://dict.variants.moe.edu.tw/)官网按字号检索。想突破这条线，需要全字库字体的 PUA 映射，或逐字抓取约 7.4 万个详情页。

另外，正字系统以台湾标准字体为准，部分大陆规范字形不在表内，查询时会自动做简繁归一。

## 使用

**本地**：用 `yitizi-single.html`（单文件离线版），双击即可打开；iOS「文件」App 的预览不执行 JavaScript，请改用浏览器。

**部署（线上拆分版）**：把 `index.html`、`data.js`、`glyphs.js` 三个文件一起放进仓库根目录，Settings → Pages → 分支选 `main`、目录 `/ (root)`，等一两分钟即可。三个文件缺一不可；首次打开需下载约 9 MB 数据。

---

## 技术

纯静态、无框架、无构建步骤。文字数据 gzip + base64 内联在 `data.js`，字形打包进 `glyphs.js`，运行时用 `DecompressionStream` 解压；缺字自动降级为字号占位。数据优先走 jsDelivr CDN，失败自动回退本地文件。

页面底部接入不蒜子（busuanzi）访问计数，用于统计浏览量与访客数，无其他追踪代码。
